This portfolio is intentionally **route-based** and **feature-driven** so it can grow into a real product-style codebase (Blog, Tools, etc.) without turning into one giant component.

## Why this setup?

- **Features-first folders**: `src/features/home`, `src/features/blog`, `src/features/tools`
- **Shared building blocks**: `src/shared/*`
- **Hash routing** for GitHub Pages: routes work without server rewrites
- Blog posts are **markdown files** in `public/content/blog/` with a small manifest in code
